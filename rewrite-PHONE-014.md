DATA: AACT 2026-04-12 snapshot (n = 2,277 registered malaria trials) · year-bins 2004–2024
PATH: C:\Projects\malaria-ct-recon

</details>

### Original (frozen — do not edit)

```
Do malaria trials registered on ClinicalTrials.gov comply with two reporting requirements — the FDAAA results-posting mandate and the WHO PCR-correction declaration in primary outcomes? AACT 2026-04-12 snapshot of 2,277 registered malaria trials, year-binned 2004–2024 by primary completion date. P01 = fraction posting results within 12 months; P03 = fraction declaring PCR-correction (strict regex plus ACPR-inclusive broad regex); Wilson 95 % CIs. Compliance is below target: P01 = 7.6 % [6.3, 9.1] of 1,420 completed trials; P03 strict = 2.8 % [2.0, 3.8] / broad = 7.7 % [6.3, 9.3] of 1,267 drug-efficacy trials. Trajectories diverge: FDAAA results-posting rose 4.0 % → 14.5 % pre/post-2017 (Fisher p < 0.001); WHO PCR-correction fell 8.1 % → 2.3 % pre/post-2009 (p = 0.008). Malaria-specific FDAAA compliance trails the ~41 % cross-disease benchmark threefold; the WHO methodological standard has not moved without enforcement infrastructure. P03 strict regex is a lower bound; trials registered only in PACTR/CTRI/ISRCTN are outside this corpus.

## Entry 669 ([678/921]) — pactr-hiddenness-atlas (2026-05-05)

<details><summary>Metadata</summary>

```
TITLE: NCT-bridge methodology is structurally blind to PACTR-registered African trial publications
TYPE: methods note  |  ESTIMAND: Algorithm gate2 sensitivity (algorithm True / auditor True) for peer-publication detection on PACTR-registered African trials
DATA: PACTR Search_v2.aspx full-registry scrape 2026-05-04 (n = 5,878 trials; 768 matched to 10 high-burden conditions); Pairwise70 study_references built from CDE; CDSR string index built from CDE; blinded 30-trial spot-check (seed=20260503, web verification)
PATH: C:\Projects\pactr-hiddenness-atlas
```

</details>

### Original (frozen — do not edit)

```
How well does NCT-bridge methodology, used by every existing ClinicalTrials.gov-style synthesis audit, capture publications from PACTR-registered African trials? We scraped 5878 PACTR trials (snapshot 2026-05-04, sha256 44f99b14), assigned 768 to ten high-burden conditions, and tracked four gates by algorithm and a blinded 30-trial spot-check. Algorithm and auditor applied identical gate definitions: gate 2 via NCT-bridge to Europe PMC (algorithm) or direct title/PACTR-ID search (auditor), and gate 3 via Pairwise70 index. Algorithm found 3.6% peer-published and 0.5% Cochrane-cited; the blinded spot-check found 53.3% peer-published (16/30) and 1 Cochrane match the algorithm missed (WOMAN trial, CDE coverage gap). Algorithm publication-detection sensitivity was 6.2%; 96.0% of trials carry no NCT cross-reference and are structurally unreachable through NCT-bridge. NCT-bridge methodology is blind to PACTR publications even when published, undercounting trial-to-publication conversion by an order of magnitude. Findings reflect 2026-05-04 snapshots; v0.2 adds PACTR-ID-direct Europe PMC search.
