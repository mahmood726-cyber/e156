- [ ] All: ISSN portal requires a sample issue page — confirm each journal's issue archive is accessible

## After ISSN is assigned

1. Enter the e-ISSN in OJS: Journal Settings → Journal → Online ISSN
2. Update the JATS XML galleys (a second repair run will fill the `<issn pub-type="epub">` elements automatically once the ISSN is in OJS)
3. Proceed with Crossref membership and DOI deposit (see pmc_infra_status.md)
